# Today in History - September 08

## Event 1
📅 Year: 1962  
📝 Event: Last run of the famous Pines Express over the Somerset and Dorset Railway line (UK) fittingly using the last steam locomotive built by British Railways, BR Standard Class 9F 92220 Evening Star.

## Event 2
📅 Year: 1727

## Event 3
